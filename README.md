# Project Title
 
My Final Project is an web app called TimeX. Timex is a time tracking app built with Django that allows users to track billable hours, manage clients, and calculate total earnings.
 
## Description
 
TimeX is designed for professionals such as lawyers, legal assistants, and freelancers who need a simple and effective way to track time and calculate billing. Users can create clients, log time entries, view a dashboard of activity, and see a summary of total hours and earnings.

The application also integrates an external API to display real-time data on the dashboard, demonstrating the use of API integration in a full-stack web application.
 
## Getting Started
 
### Dependencies

Clone the repository: git clone https://github.com/YOUR-USERNAME/finalprojectKevinVasquez.git

Please install the pip requirements:
```

pip install -r requirement.txt
```
 

 
### Executing program

In terminal, please type:
```
python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```
